# Desafio Colaborativo Git 🔧

Este repositório faz parte dos meus primeiros exercícios com **Git e GitHub**.

Criei este espaço durante os estudos de introdução ao versionamento para começar a me familiarizar com a organização dos repositórios e o registro das alterações.

## 📖 O que estou aprendendo

Meu objetivo com exercícios como este é entender melhor como funciona o histórico de versões e como o GitHub pode ajudar no desenvolvimento e na colaboração.

Por enquanto, este repositório contém a apresentação da atividade. Conforme eu adicionar novos arquivos ou exemplos práticos, vou documentá-los aqui.
